# Background music

Add your wedding theme track here as:

```
assets/music/wedding-theme.mp3
```

The player in `index.html` / `script.js` looks for that exact path (configurable via `WEDDING_CONFIG.music.src` in `config.js`). Keep the file reasonably small (under ~5MB) for fast loading, and make sure you have the rights to use the track on a public site.
